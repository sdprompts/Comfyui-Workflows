# ComfyUI Workflows

Beginner workflows that load in stock ComfyUI. Drag a JSON file onto the canvas. Each graph has a note with the model download links.

The Viggle Qwen graphs are the exception: copy `viggle_turbo.py` into `ComfyUI/custom_nodes/` and restart. The note in those files has the link.

## Workflows

- **MOSS Image** — text to image
- **Krea 2** — Raw model with the turbo LoRA at 0.6 and the Wan 2.1 VAE
- **Qwen 2.1** — text to image and image edit, plus int8 turbo and Viggle turbo versions
